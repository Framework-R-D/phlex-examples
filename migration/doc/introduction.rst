Introduction
============

This document provides guidance for migrating from the *art* framework to
*Phlex*.  Each section covers a common pattern or concept from *art* and
explains how the equivalent functionality is expressed in *Phlex*.

Migration examples are provided in the ``migration/`` directory of the
``phlex-examples`` repository.  Each subdirectory contains a self-contained
example that demonstrates the migration of a specific *art* component.
